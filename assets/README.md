# HAKHAM official avatar asset

Place the approved transparent Hakham avatar here as:

`assets/hakham-avatar.webp`

The Control Center v0.5 detects this file automatically and serves it through `/assets/hakham-avatar`.

Alternative local file:

`HAKHAM_AVATAR_FILE=C:\path\to\hakham-avatar.png`

Alternative hosted image:

`HAKHAM_AVATAR_URL=https://...`

Do not commit credentials or private signed URLs.
